# Simplico (Versão Clássica )

> *O ponto de partida de tudo.*

Este repositório preserva o **código original** do **Simplico**, desenvolvido em **2017** e projetado nativamente para o **Python 3.6**. 

## 📜 Sobre o Projeto
O Simplico nasceu com uma proposta direta e focada em automação leve: permitir a criação de sistemas locais e coleta de dados através de comandos legíveis em formato humano, sem burocracia ou estruturas complexas.

Este código foi mantido **exatamente como foi escrito em 2017**, servindo como um fóssil digital e um marco histórico da evolução de desenvolvimento.



## 🚀 Como Executar
Feito para rodar em ambientes compatíveis com o **Python 3.6+**:
```bash
python simplico.py
